# VPN Access Runbook

Runbook for connecting to the corporate network remotely. Synthetic demo content.

## Installing the Client

Install the NorthGate VPN client from the Software Center. The client is supported on Windows 11 and macOS 14 or later.

## Resetting a VPN Token

To reset your VPN token, open the self-service portal, choose "Reset VPN token" and confirm the request with the Authenticator app. A new token is issued immediately and is valid for 90 days.

## Getting Help

If the reset fails, contact the IT Service Desk on extension 4357 and quote the error code shown by the client.
